# Складская система (Sklad)

Личная складская система с мультивалютой, накладными, Telegram-ботом и публичным каталогом.
PWA + Vercel serverless + Supabase. Фронтенд — ванильный JS (ES-модули), без сборщика.

## Запуск локально

Статический сайт, без сборки. Превью:
```
npx -y serve -l 5500
```
(конфиг уже есть в `.claude/launch.json`, имя сервера — `static`).

- Админка: `index.html#/?key=<SECRET_KEY из config.js>`
- Каталог: `catalog.html`
- Без заполненного Supabase в `config.js` работает **локальный демо-режим** (данные в браузере).

## Деплой

Хостинг — **Vercel**. Serverless-функции в `api/*`. Секреты (токен Telegram-бота и т.п.)
лежат в переменных окружения Vercel, **не** в репозитории. См. `vercel.json`, `SETUP.md`.

## Структура проекта

```
index.html          — админка (SPA, монтирует js/app.js)
catalog.html        — публичный каталог товаров
config.js           — настройки (Supabase URL/anon key, SECRET_KEY, валюты). НЕ секрет: всё уходит в браузер
css/theme.css       — ВСЯ тема и дизайн (светлая + тёмная)
manifest.webmanifest, sw.js — PWA

js/
  app.js            — точка входа SPA, роутинг
  auth.js           — вход (Supabase Auth онлайн / пароль в локальном режиме)
  db.js             — слой данных (Supabase или localStorage)
  i18n.js           — переводы (ru/uz/…)
  ui.js, fx.js, effects.js, icons.js, charts.js — UI-утилиты, иконки, анимации, графики
  catalog.js, inventory.js, telegram.js
  pages/            — страницы: dashboard, products, sales, purchases, orders,
                      customers, reports, settings, catalog_admin

api/                — Vercel serverless: telegram.js, order.js, upload.js, bot.js
  lib/              — auth.js, supa.js, pdf.js (PDF-накладные), debt.js
  fonts/            — NotoSans для PDF

db/schema.sql       — схема БД Supabase
```

## Стек

- Фронт: ванильный JS (ES-модули), без фреймворка и сборщика
- Бэкенд: Vercel serverless (Node)
- БД/Auth: Supabase (есть fallback на localStorage — локальный режим)
- Telegram-бот: отправка накладных/заказов, PDF через `pdf-lib`
- PWA: manifest + service worker (`sw.js`)

## Дизайн-система (строгий профессиональный стиль)

Всё в `css/theme.css`. Темы через `html[data-theme="light"|"dark"]`, по умолчанию — `light`.
Шрифт — **Inter** (подключён в `index.html` и `catalog.html` через Google Fonts).

Ключевые токены (CSS-переменные):

| Токен      | Светлая    | Тёмная     | Назначение                         |
|------------|------------|------------|------------------------------------|
| `--bg`     | `#f5f6f8`  | `#0e1117`  | фон                                |
| `--panel`  | `#ffffff`  | `#161b22`  | модалки/поверхности                |
| `--text`   | `#16191f`  | `#e6e9ef`  | основной текст                     |
| `--muted`  | `#667085`  | `#8b93a3`  | вторичный текст                    |
| `--accent` | `#2f5bd0`  | `#4f7cf0`  | акцент (синий, сдержанный)         |
| `--accent2`| `#1f2937`  | `#6b97f5`  | графит: кнопки/активная навигация  |
| `--radius` | `10px`     | `10px`     | скругление карточек                |

Принципы строгого стиля (соблюдать при правках):
- Скругления небольшие: карточки `10px`, кнопки/инпуты `8px`, бейджи `6px`.
- Тени лёгкие и нейтральные (`0 1px 2px …`), без крупных цветных свечений.
- Ховер сдержанный: сдвиг 1–2px, без «подпрыгиваний» и фиолетового свечения.
- Никаких плавающих цветных «орбов» в светлой теме (отключены).
- Акцент — один сдержанный синий; графит для primary-кнопок и активного пункта меню.
