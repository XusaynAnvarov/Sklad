# GENERAL MODERN — настройка бота в @BotFather

Бот: **@generalmodernbot**

Аватар и картинку/описание бота **нельзя поставить через код** — только вручную в @BotFather.
Все нужные файлы уже готовы в папке `brand/`. Ниже — что и куда загрузить (2–3 минуты).

---

## 1. Аватар бота (логотип) — обязательно

Аватар виден **до** нажатия «Start», на экране чата и в списке. Это и есть «логотип при входе».

1. Открой **@BotFather** → отправь `/setuserpic`
2. Выбери бота **@generalmodernbot**
3. Отправь файл **`brand/bot-avatar.png`** (512×512, логотип GM)

> Альтернатива: `/mybots` → @generalmodernbot → **Edit Bot → Edit Botpic** → загрузить тот же файл.

---

## 2. Описание (текст до «Start») — рекомендуется

Текст показывается на пустом экране чата, **до** нажатия «Start».

1. **@BotFather** → `/setdescription`
2. Выбери бота → вставь текст, например:

```
GENERAL MODERN — каталог и заказы. Нажмите «Старт», чтобы открыть каталог товаров, узнать оборот и долг, получить накладные в PDF.
```

Короткое описание (в профиле): `/setabouttext` →
```
GENERAL MODERN — ваш каталог и заказы в Telegram.
```

---

## 3. Анимация логотипа при входе — уже работает в коде

После деплоя бот **сам** показывает анимированный логотип сразу при `/start`
(файл `brand/bot-intro.gif`, отправляется через `sendAnimation` — см. `api/bot.js`).
То есть как только клиент впервые открывает бота и жмёт «Start» — первым приходит
анимация GENERAL MODERN, затем выбор языка. Никаких действий от вас не требуется.

> Важно про «до нажатия Start»: Telegram **не разрешает** боту присылать что-либо,
> пока пользователь не нажал «Start». Поэтому до старта виден логотип-**аватар** (п.1)
> и текст-описание (п.2), а анимация проигрывается в первую же секунду после «Start».
> Если в вашем @BotFather есть пункт **Edit Bot → Description Picture** — можно
> дополнительно загрузить туда `brand/bot-intro.gif` (этот пункт есть не у всех ботов).
