# Что делать, если что-то случится

Составлено 22 августа 2026. Держите этот файл под рукой — он в репозитории,
значит доступен с любого компьютера.

---

## Где что лежит

Система состоит из трёх независимых частей. Потеря одной не убивает остальные.

| Что | Где | Если пропадёт |
|---|---|---|
| **Код** (сайт, склад, бот) | GitHub, `XusaynAnvarov/Sklad` | Восстанавливается одной командой |
| **Данные** (товары, клиенты, накладные, долги) | Supabase, проект `ttgcrcloioznojreogwn` | **Восстановить неоткуда**, кроме вашей копии |
| **Фотографии и видео** | Supabase Storage | **Восстановить неоткуда** |
| **Секретные ключи** | Файл `.env` на сервере | Придётся выпускать заново |
| **Логин и пароль склада** | `data/admin-creds.json` на сервере | Задаются заново |
| **Ключ доступа к серверу** | `~/.ssh/id_ed25519` на ноутбуке | Восстанавливается через хостинг |

**Сайт, бот и склад работают на сервере, а не на ноутбуке.** Ноутбук можно
разбить, потерять или продать — торговля не остановится ни на минуту.

## Ноутбук: вирус, покупка нового, продажа старого

### Что с ноутбука обязательно забрать

Всего одна папка:

```
C:\Users\ASUS\.ssh\
```

Там ключ доступа к серверу. Он существует **в единственном экземпляре**.
Скопируйте её на флешку или в переписку с самим собой в Telegram.

Всё остальное с ноутбука не пропадёт: код лежит в GitHub, данные в Supabase.

### Перед продажей ноутбука

1. Скопировать папку `.ssh` (см. выше).
2. Выйти из GitHub, Telegram, Supabase в браузере.
3. Стереть диск полностью — не просто удалить файлы, а форматировать.
   На ноутбуке остаются сохранённые пароли браузера и доступ к серверу.

### Если ключ доступа всё-таки потерян

Не страшно. Заходите в панель хостинга (Hetzner), там есть консоль прямо в
браузере — через неё добавляете новый ключ. Сайт при этом продолжает
работать, просто вы временно не можете чинить сервер напрямую.

## Новый ноутбук: что поставить

Всё, что нужно для работы, — **браузер и Telegram**. Складом можно
пользоваться с любого устройства:

- склад на компьютере — `generalmodern.uz/admin`, логин и пароль;
- склад в телефоне — кнопка в боте;
- каталог и заказы — работают сами.

**Ничего устанавливать не нужно**, если вы не собираетесь править код.

### Если хотите править код

```bash
git clone https://github.com/XusaynAnvarov/Sklad.git
cd Sklad
npm install
```

Плюс поставить [Node.js](https://nodejs.org) (версия 20 или новее) и
[Git](https://git-scm.com). Затем вернуть папку `.ssh` на место — в
`C:\Users\<ваше имя>\.ssh\` — чтобы снова иметь доступ к серверу.

## Если что-то случится с Supabase

Там лежат **все данные и все фотографии**. На бесплатном плане Supabase
резервных копий не делает — так и написано на странице проекта:
«Резервных копий нет».

### Единственная защита — ваша копия

Склад в телефоне → **«Ещё» → «Скачать копию базы»**. Получится один файл со
всеми товарами, клиентами, накладными, приходами и оплатами.

**Делайте это раз в неделю.** Файл сразу отправляйте себе в Telegram — копия
на том же телефоне не спасёт, если телефон потеряется.

### Чего в копии НЕТ

**Фотографий.** В файле лежат ссылки на снимки, а не сами снимки. Если
Supabase пропадёт, фотографии придётся снимать заново.

## Если что-то случится с сервером

Сервер — Hetzner, адрес `116.203.153.224`, домен `generalmodern.uz`.

Восстановление на новом сервере:

1. Поставить Node.js, nginx, pm2.
2. `git clone` репозитория в `/var/www/skladanvarov`.
3. Создать `.env` — образец в файле `.env.example`, значения взять из старого
   сервера или выпустить заново (токены ботов — у @BotFather, ключ Supabase —
   в панели проекта).
4. Скопировать `deploy/nginx-generalmodern.conf` в
   `/etc/nginx/sites-available/`, включить, получить сертификат через certbot.
5. `pm2 start server.js --name sklad-api`
6. Переключить домен на новый адрес в Cloudflare.

Данные при этом не трогаются — они в Supabase.
